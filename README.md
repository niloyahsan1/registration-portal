# General Registration Portal
A clean, responsive, web registration portal for any event.


## Features
- Interactive Live Countdown
- Registration Form
- Instant Digital Ticket Generation
- One-Click Ticket Download
- Serverless Backend (Google Apps Script)
- Modern Design System


## Tech Stack
- Frontend: HTML5, Vanilla CSS3
- Scripting: JavaScript
- Backend/Storage: Google Apps Script & Google Sheets
- Libraries: html2canvas


## Project Structure
```text
registration-portal/
├── index.html        # Workshop landing page with details & live countdown
├── register.html     # Registration form and ticket download view
├── style.css         # Main stylesheet & custom modern light design system
├── assets/           # Static asset directory
└── README.md         # Project documentation
```
