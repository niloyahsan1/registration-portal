# General Registration Portal
A clean, responsive, and modern web registration portal designed for events, workshops, and seminars. Built using HTML5, Vanilla CSS3, and JavaScript, with a serverless Google Apps Script & Google Sheets backend and html2canvas for instant digital ticket pass generation.


## Preview
![Registration Portal Preview](assets/preview.png)


## Features
- Interactive Live Countdown
- Automated Registration Closure
- Structured Multi-Step Registration Form
- Instant Digital Ticket Pass
- One-Click Ticket Download
- Serverless Backend (Google Apps Script)
